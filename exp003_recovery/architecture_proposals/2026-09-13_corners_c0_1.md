# ARCHITECTURE PROPOSAL — C0.1 CORNERS SHADOW

Timestamp context: 2026-09-13 pre-settlement of current target fixtures.
Status: SHADOW ONLY / NOT PRODUCTION-ELIGIBLE.
Parent laboratory governance: DTL-1.2.

## Rationale
Add corner-kick markets to the project without changing the existing Dixon-Coles goals model. Corners are a distinct count process and must be modeled separately.

## Frozen C0.1 choices
- Model family: team attack/defense Negative Binomial corner counts.
- Parameters: corner attack, corner defense, global intercept, home-corner advantage, shared dispersion k.
- Time decay: literal half-life ensemble 180/365/730/1460 days.
- C0.1 home/away corner counts are conditionally independent; the joint matrix is an outer product. This is an explicit limitation to test, not a hidden truth claim.
- Data target: per-match completed Liga MX corners from FotMob matchDetails, admitted only before explicit cutoff.
- Outputs may be computed/logged for total corners, team corners and most-corners markets.
- No corner market is REAL-stake eligible merely because it can be computed.

## Architecture changes requiring a new version
- bivariate/correlated count structure or copula;
- new half-lives;
- xG/shots/possession/crosses/game-state/context features;
- different dispersion structure;
- calibration layer;
- market eligibility/staking rules.

## Promotion evidence
C0.1 begins with zero forward production evidence and therefore cannot clear the DTL promotion gate. Historical walk-forward and forward shadow predictions must be logged separately. Correlated markets from the same match must be priced from the corner joint matrix, never by multiplying marginal probabilities.
