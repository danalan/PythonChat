# LENNON — External Match Opinion Panel

Effective immediately: 2026-09-18

When Carlos asks for analysis or an opinion about a football match, present the following sources separately whenever current coverage exists:

1. LENNON
2. Squawka
3. SportsGambler
4. Forebet
5. PredictZ
6. WinDrawWin
7. BetClan
8. Sports Mole

If a source has no current view for the exact fixture or requested market, report N/A / NO CURRENT COVERAGE. Do not invent or silently substitute a source.

After the source panel, add a CONTEXT section using only information available before kickoff: injuries, suspensions, expected or confirmed lineups, manager or tactical changes, recent form, home/away splits, rest, travel, congestion and other material team news.

Context remains separate from LENNON p_model and is tagged SUPPORT, NEUTRAL, CONTRADICT_LOW, CONTRADICT_HIGH or UNKNOWN.

Then add a SYNTHESIS section explaining agreement and disagreement among LENNON, external sources and context. Do not automatically average their percentages. External sources remain external signals and do not alter LENNON core probabilities without a separately validated architecture change.

For corner analysis, only use sources that provide corner-specific statistics or predictions. Never infer a corner view from a match-winner prediction.

Default display order:
LENNON → Squawka → SportsGambler → Forebet → PredictZ → WinDrawWin → BetClan → Sports Mole → CONTEXT → SYNTHESIS
